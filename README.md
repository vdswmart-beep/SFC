# SFC

Master's thesis workspace (ICHEC, Master en Sciences Commerciales, 2026-27):
*From Smart Beta to Active Management: Integrating Quantitative Factor Signals and Fundamental
Analysis into Long/Short Equity Portfolio Construction.*

- `ls_backtest/`: V1 backtest of the equitized long/short strategy, with a long-only switch and
  a web app that explains the model and its holdings (`streamlit run app.py`). Start with
  [ls_backtest/README.md](ls_backtest/README.md).

Data are never versioned: Bloomberg data are licensed, Yahoo data can be downloaded again.
